Permanent design direction requested by the owner on 5 November 2026.
This document records the actionable standard supplied in the redesign request;
the linked ChatGPT export exposes reference markers instead of the full original
prompt and mockup. It is not a verbatim reconstruction of that missing content.

## SMARTTAP: Concept B — The Connected Hub

- Product: a business-premises NFC/QR service for Google Review, WhatsApp,
  social links, catalogues, owner editing, super-admin management and subscriptions.
- Palette: cool light lavender/periwinkle, white surfaces, energetic purple
  actions, dark violet text. Avoid returning to the old cream/green app chrome.
- Identity: retain the owner's selected SMARTTAP artwork; pair it with a bold
  SMART/TAP wordmark and a restrained connected-orbit motif. No generic metrics.
- Typography: native Segoe UI Variable / Segoe UI / system sans, strong compact
  headings, readable controls, 14px body content in mobile account workflows.
- Composition: permanent desktop owner navigation, a focused scrollable work
  area, real status and subscription data, a mobile drawer and usable tabs.
- Public pages: business identity first, Google Review and WhatsApp accessible,
  clear location/catalogue links, sharing and business details. Retain the
  customer's stored accent, dark theme, logo, cover and optional content.
- Media: reuse the existing salon/restaurant artwork, clearly labelled fiction.
  Never invent real customer activity, reviews, conversion rates or revenue.
- Interaction: preserve existing handlers and API contracts. Support loading,
  empty, error, disabled, focus, selected and success states. Respect reduced
  motion. Maintain visible keyboard focus, semantic controls and AA contrast.
- Release: fresh tests, browser interaction evidence, desktop/mobile captures,
  accessibility checks, preview verification, known production rollback point,
  production smoke test and an honest account of unverified flows.
